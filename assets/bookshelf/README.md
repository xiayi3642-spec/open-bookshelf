# 我的书架 · Study Shelf

手机 / 平板 / 电脑三端可用的学习卡片书架。书墙封面陈列，点击在线阅读（PDF.js），支持下载。

## 目录结构

```
bookshelf/
├── index.html          # 书架主页（书墙 UI + 阅读器）
├── index.json          # 书架索引（我维护，加书时更新）
├── README.md           # 本说明
├── books/              # 卡片 PDF 原文件
├── covers/             # 封面缩略图（每册第 1 页）
└── vendor/pdfjs/       # PDF.js 阅读引擎（本地离线）
```

## 怎么打开

书架必须通过 HTTP 访问（浏览器安全限制，直接双击 index.html 无法加载 PDF）。任选其一：

```bash
# 方式 1：Python（最简单）
cd bookshelf && python3 -m http.server 8931
# 浏览器打开 http://localhost:8931/

# 方式 2：放到云电脑 / 静态托管后，直接访问对应网址
```

放到云电脑后，手机/平板/电脑浏览器打开书架网址即可，支持 `?open=书号` 直接定位某本书（如 `index.html?open=03`）。

## 阅读器操作

- `‹` `›` 或键盘 `←` `→`：翻页；`Esc`：关闭
- `−` `＋`：缩放；`宽`：回到适应宽度
- `下载 PDF`：保存到本机
- 阅读位置自动记忆（浏览器本地存储），下次打开自动续读，书架上显示"读到第 N 页"角标

## 怎么加书

把新卡片 PDF 放入 `books/`，命名规范：`序号-课程-标题.pdf`，然后在 `index.json` 中按既有格式追加一条：

```json
{
  "id": "12",
  "title": "标题",
  "course": "所属课程（需与分组一致）",
  "desc": "风格/备注",
  "file": "books 里的文件名",
  "cover": "封面文件名（放入 covers/，可用第一页截图）",
  "date": "2026-10-30",
  "pages": 10,
  "sizeMB": 5.2
}
```

刷新书架页即出现。之后直接对我说「放进书架」即可，由我来维护。
